# TOKI-刻 公式サイト 更新ガイド

このフォルダは、TOKI-刻の公式サイトを「新曲が出るたびに簡単に更新できる」ようにした仕組みです。

## フォルダの中身

| ファイル | 役割 | 触っていい？ |
|---|---|---|
| `index.html` | 公開する完成品。ビルドすると自動で作り直される | ✋ 直接編集しない（ビルドで消えます） |
| `songs.json` | 曲のリスト。**普段編集するのは基本ここだけ** | ○ ここを編集する |
| `template.html` | デザインの原本 | ✋ 触らない（デザイン変更したい時はClaude Codeに相談） |
| `build.py` | songs.json をデザインに流し込む道具 | ✋ 触らない |
| `images/` | アイコンとジャケット画像の置き場 | ○ 画像を追加する |

## 新曲リリース時の手順

### 1. ジャケット画像を入れる

ジャケット画像（正方形のjpg）を `images/` フォルダに入れます。
ファイル名は英数字がおすすめです（例: `new-song.jpg`）。

※ 画像がまだ無くても大丈夫。その間は「TOKI」マークのプレースホルダーが表示されます。

### 2. songs.json に新曲を追加する

`songs.json` をテキストエディタで開いて、**一番上**（`[` のすぐ下）に新曲のブロックを追加します。

```json
  {
    "title": "新曲のタイトル",
    "subtitle": "Single / 2026",
    "link": "https://linkco.re/xxxxxxxx?lang=ja",
    "image": "images/new-song.jpg",
    "latest": true
  },
```

あわせて、**前の曲の `"latest": true` を `"latest": false` に変えます**
（LATESTバッジが2曲に付かないように）。

書き方のルール:

- 並び順 = サイトでの表示順。新しい曲ほど上に書く
- `latest: true` の曲にだけ「LATEST」バッジが付く（1曲だけ）
- リンク先がまだ決まっていない時は `"link": ""` と空にしておく（カードは表示され、リンクだけ無効になる）
- ブロックとブロックの間の `,`（カンマ）を忘れずに。最後のブロックの後ろにはカンマを付けない

### 3. ビルドする

ターミナルでこのフォルダに移動して、次の1行を実行します。

```
python3 build.py
```

成功すると「○ index.html を作りました（7曲分の曲カードを生成）」のように表示されます。
songs.json の書き方にミスがあると、何行目が怪しいか日本語で教えてくれるので、直してもう一度実行してください。

### 4. 公開する

できあがった `index.html` と `images/` フォルダを公開先にアップロードします。

## Claude Code に頼む場合（おすすめ）

手順1〜3は、Claude Code に日本語で頼むだけでもできます。例:

> 新曲『夜明けのカノン』を追加して。linkco.reはこれ→ https://linkco.re/xxxxxxxx?lang=ja 。ジャケは images/yoake-no-canon.jpg。LATESTを付け替えてビルドまでやって

> 『揺るがない推し』のlinkco.reが決まったので設定して→ https://linkco.re/xxxxxxxx?lang=ja 。ビルドもお願い

> 曲の並び順を変えたい。『ダラリーマン』を一番上にしてビルドして

## よくある質問

**Q. デザインや文章を変えたい**
`template.html` が原本ですが、直接触らずClaude Codeに「〜を変えて」と頼んでください。

**Q. ビルドしたらエラーで止まった**
表示された日本語メッセージの行あたりを確認。多いのはカンマの付け忘れ・付けすぎです。直せない時はエラーメッセージごとClaude Codeに貼り付けてください。

**Q. 連絡先メールアドレス**
フッターの封筒アイコンから連絡先メールが開きます。迷惑メール対策のため、アドレスは
ページ内にそのまま書かず、表示した瞬間に組み立てる仕掛けになっています。変更したい時はClaude Codeに頼んでください。
